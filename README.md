SchoolSpace est une application web dédiée à la gestion des espaces éducatifs au sein d’un établissement scolaire.
Elle permet d’organiser, superviser et optimiser le fonctionnement de différents espaces tels que l’espace scolaire, l’espace comptabilité, et autres services internes.

L’application repose sur deux portails principaux :

🔐 Portail Administrateur :
L’administrateur dispose d’un contrôle complet sur le système. Il peut :

Créer, modifier et supprimer les espaces
Gérer les employés associés à chaque espace
Affecter des tâches aux employés
Superviser l’ensemble des activités

👨‍💼 Portail Employé :
Les employés peuvent :

Consulter les tâches qui leur sont assignées
Suivre l’état de leurs missions
Valider les tâches réalisées
